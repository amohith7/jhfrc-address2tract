      How it works

      1

      Upload

      Choose a spreadsheet with an ID and address columns. It is read inside this tab and checked for personal details before anything else happens.

      2

      Match

      Each address is looked up with the U.S. Census Bureau geocoder, then OpenStreetMap for the few the Census cannot find.

      3

      Download

      Review the results, fix any unmatched addresses, and download a share file with only the ID, tract and match status.

      Your data stays with you

      The file is opened and processed in this browser tab. It is never uploaded to or stored on this website. Only the address text of each record is sent to the U.S. Census Bureau geocoder, and for addresses the Census cannot find, to the OpenStreetMap Nominatim geocoder.

      • Files with sensitive column names (name, DOB, phone, email and others) are refused at upload.
      • Cells that look like emails, phone numbers, SSNs, dates or names before an address are refused too.
      • The file you send to JHFRC holds only the ID, tract and match status.

      Questions

      What do the match statuses mean?
      Matched
      Found by the Census geocoder in its current address file.
      Matched_Fallback
      Found by the Census geocoder in its 2020 address file, or after tidying the street abbreviation.
      Matched_External
      Located by the OpenStreetMap Nominatim geocoder, then assigned to its Census tract.
      No_Match
      No geocoder could place the address. Check it for typos or a missing street number. PO boxes are never matched because they have no physical location.
      Rejected
      The row was missing its ID or its address.
      Which tract boundaries are used?

      The Census Bureau's current tract boundaries, as returned by the Census geocoder. Tract codes are 11 digits: state (2), county (3) and tract (6).

      My file has more than rows.

      The page offers to split it into parts you can run one after another. For very large files, the command-line version of this tool is much faster.

      I fixed an address. Which file shows the change?

      results.xlsx gains a corrected_address column next to your original address, so you can update your own records. The share file is unchanged in format.
